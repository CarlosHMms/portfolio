# 💘 LoveTracker – Diário de Relacionamento Digital

Um site romântico e simbólico onde casais podem acompanhar o tempo de relacionamento, registrar momentos especiais e ganhar estrelas a cada dia juntos. A cada ano, algo mágico acontece! ✨

---

## 🌟 Funcionalidades

- Cadastro de casal com data de início do relacionamento
- Contador de tempo em dias, meses e anos
- Cada dia adiciona uma estrela na constelação do casal
- Eventos especiais a cada ano (medalhas, mensagens, surpresas)
- Área privada com login
- Timeline com registros do casal (fotos, bilhetes, datas marcantes)
- Alertas e mensagens personalizadas em aniversários de namoro

---

## 🛠️ Stack utilizada

### Back-End:
- Java 24
- Spring Boot
- Spring Security (JWT)
- Spring Data JPA
- PostgreSQL
- API RESTful

### Front-End:
- Angular
- TailwindCSS ou styled-components
- Axios para consumo da API
- Animações com Framer Motion ou React Spring

---

## 🔐 Autenticação

- Login por e-mail e senha
- Autenticação via token JWT
- Criptografia de senhas com BCrypt

---

## 🧠 Lógica Principal

- Calculadora de tempo desde a data de início
- Geração de estrela diária
- Sistema de recompensas anuais (desbloqueios visuais ou afetivos)

---

## 🚀 Hospedagem sugerida

- Front-end: Vercel ou Netlify
- Back-end: Railway, Render ou VPS
- Banco de dados: Supabase (PostgreSQL) ou Planetscale (MySQL)
